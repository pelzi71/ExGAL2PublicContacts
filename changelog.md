# Changelog

All notable changes to ExGAL2PublicContacts will be documented in this file.

The project follows Semantic Versioning.

## [0.1.0] - Development

### Added

- Initial project structure
- EWS Managed API connection
- Windows Authentication
- Public Folder path resolution
- Public Folder Contact reading
- Exchange UserMailbox reading
- Active Directory account status detection
- SMTP address based contact matching
- Read-only comparison
- Detailed text logging
- Statistics and execution summary

### Important

Version 0.1.0 is a development version.

No Public Folder contacts are created, modified or deleted.
